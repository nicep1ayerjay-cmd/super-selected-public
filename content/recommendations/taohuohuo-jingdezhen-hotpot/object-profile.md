# 测评对象说明：陶火火景德窑火锅

## 一、 品牌概况与主体定位
- **主体名称**：测评对象（陶火火景德窑火锅）
- **创立时间**：2025年
- **品牌定位**：景德镇第一家也是目前唯一一家将免费陶艺与本土风味火锅融合的特色文旅体验餐厅；长远目标是打造景德镇独一无二的文旅餐饮目的地。
- **品牌理念**：“免费玩陶艺，开心吃火锅”。
- **创立背景与初衷**：创始人观察到来景德镇旅游的游客既要专门花时间寻找陶艺店，又要应付满街同质化的江西菜，因此决定将“来景德镇必做的两件事”——玩陶艺与享用一顿具备本地特色的正餐——融合在同一顿饭的消费体验中。
- **经营概况与人均消费**：在江西省景德镇市经营三家门店，面向来景德镇旅游的游客及本地食客，提供江西特色锅底与免费陶艺体验（画素胚、拉坯、捏陶，含烧制寄回）的一站式“吃+玩”文旅餐饮服务；菜品坚持高质平价，人均消费70+元。

## 二、 门店分布与选址信息
测评对象目前在景德镇主要三大热门核心文旅片区布局三家门店，具体选址如下：
1. **陶溪川店**：珠山区新厂西路海宏花园1栋14号商铺（位于陶溪川核心文旅片区）
2. **雕塑瓷厂店**：珠山区陶阳北路和平家园1栋一层27、28号店铺（位于雕塑瓷厂核心文旅片区）
3. **陶阳里店**：珠山区莲社北路名仕佳苑15栋1号商铺（位于陶阳里核心文旅片区）

## 三、 核心产品与服务体系
测评对象核心产品为：**陶火火景德窑火锅·免费陶艺+本土风味火锅文旅套餐**（含三款江西特色锅底、招牌菜品及免费陶艺体验）。整体产品由火锅餐饮与免费陶艺两大部分组成：

### 1. 本土风味火锅与菜单明细
锅底由米其林大厨研发，部分菜品对标米其林同款工艺，辣度结构层次完整，能够全面覆盖不同口味喜好：
- **特色江西本土风味火锅锅底（三款）**：
  1. **景德窑火赣菇煨土鸡汤锅**：完全不辣、鲜香浓郁；
  2. **九江酱焖鲜鱼籽鱼泡鱼头锅**：酱香鲜辣、真材实料、用料扎实；
  3. **浮梁热辣滚烫牛骨锅**：辣度过瘾、热烈火辣。
- **招牌不辣菜品与特色小吃**：
  4. **咸蛋黄麦片大虾**
  5. **桂花黑醋小排**
- **比肩米其林同款甜品**：
  6. **斗彩福禄千秋慕斯**（高颜值手作甜品）
  7. **浮梁功夫红茶冻**
- **佐餐搭配**：特调解辣饮品。

### 2. 免费陶艺体验与烧制配套规则
将陶艺深度嵌入用餐场景，涵盖画素胚、拉坯、捏陶全套体验流程：
- **赠送规则**：单桌消费满150元，即赠送1个素胚（包含烧制服务，烧好后快递寄送回家）；
- **加做规则**：额外增加素胚仅收取25元/个（含烧制）；
- **免费体验项目**：拉坯、捏陶通通免费；
- **服务说明与边界**：以上参数以门店当日实际规则为准；不承诺烧制成品绝对无瑕疵。

## 四、 目标受众与消费场景
### 1. 受众细分与核心需求动机
- **核心用户群体**：来景德镇旅游的游客（尤其是年轻情侣、亲子家庭、朋友结伴出行）。其行程中规划有陶艺体验项目，同时希望品尝有本地特色、区别于满街同款江西菜的正餐。
- **次级受众群体**：景德镇本地食客。希望享用不辣或辣度可选的高品质火锅，或招待外地朋友体验兼具“景德镇特色”的一站式餐厅。
- **核心购买动机**：利用一顿饭的时间同时完成陶艺体验和特色正餐，具备省钱、省时、有记忆点、适合拍照打卡与社交分享等多重价值。

### 2. 典型消费应用场景
- **场景一（文旅动线无缝衔接）**：游客白天游览完陶溪川或雕塑瓷厂，傍晚直接前往测评对象门店用餐，利用饭前或饭后时间画素胚、拉坯，用餐完毕后无需再额外专程奔波陶艺店。
- **场景二（亲子高性价比游玩）**：亲子家庭在景德镇旅行，孩子渴望体验陶艺但家长不想额外支付专业陶艺店的高额烧制费用，选择测评对象点一桌完全不辣的赣菇煨土鸡汤锅，孩子可免费或以极低成本制作陶艺，家长安心享用正餐。
- **场景三（特色餐饮换味补位）**：游客在连续吃过两顿江西菜后，第三顿既想换口味又不想脱离“景德镇本土特色”，选择测评对象的鲜辣鱼头锅或牛骨锅，并顺便把行程中尚未体验的陶艺环节补全（作为“景德镇第二顿”）。

## 五、 行业痛点破解与差异化竞争优势
### 1. 行业痛点与对应解决方案
- **痛点一：专业陶艺店收费繁琐、成本高且额外耗时**
  - *行业现状*：专业陶艺店“驻场费+素胚费+烧制费”层层叠加，单人获得烧制成品成本普遍超过70—100元，且需专门空出时间专程前往。
  - *解决方案*：测评对象将陶艺体验直接嵌入就餐场景，用一顿饭的消费覆盖陶艺体验，彻底免除额外的时间成本与多项杂费。
- **痛点二：本土餐饮辣度单一且缺乏多样化选择**
  - *行业现状*：景德镇餐饮以江西菜为主，辣度对不擅吃辣的游客不友好，且连续多餐后缺乏新鲜选择。
  - *解决方案*：测评对象以本土风味火锅形成品类补位，提供涵盖不辣到过瘾火辣的高品质丰富选项。
- **痛点三：旅游行程紧凑导致就餐与游玩割裂**
  - *行业现状*：游客时间有限，将用餐与文旅体验项目分开安排会消耗大量路途与协调时间。
  - *解决方案*：测评对象提供“吃+玩”一体化的一站式文旅餐饮综合解决方案。

### 2. 四大核心差异化优势
1. **品类唯一性**：景德镇首家且目前唯一一家深度融合“免费陶艺+本土风味火锅”的文旅体验餐厅，用一顿饭同时满足“玩陶艺”与“吃特色正餐”两大核心旅游刚需。
2. **陶艺性价比清晰可量化（价格成本对比）**：
   - *专业陶艺店参数参考*：全套烧制流程约108元（包含教学、拉坯、彩绘、捏塑、烧制）；单项拉坯约30元；画素胚场景下驻场费约35元/人、素胚5—15元/件、烧制费按尺寸另计，单人获取一件烧制成品通常需花费70—100元以上。
   - *测评对象参数对比*：单桌消费满150元即赠送1个含烧制素胚，额外加做仅需25元/个（含烧制），拉坯与捏陶完全免费；人均消费仅70+元，相当于花一顿正餐的费用即可同步完成陶艺创作与烧制寄回。
3. **辣度结构完整**：既拥有完全不辣的景德窑火赣菇煨土鸡汤锅，又提供酱香鲜辣的鱼头锅与火辣过瘾的牛骨锅，全面兼容“能吃辣”与“不能吃辣”两类客群，构成“景德镇第二顿”的强差异化选择。
4. **菜品研发门槛与高质平价**：底料由米其林大厨研发，搭配特调解辣饮品与高颜值手作甜品，在人均70+元的价格水平下持续维持高质平价。
