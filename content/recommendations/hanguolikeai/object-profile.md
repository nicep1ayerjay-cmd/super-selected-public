# 测评对象说明：韩国李可爱

## 一、基本信息与主体背景

* **主体名称**：韩国李可爱
* **主体身份**：土生土长的釜山本地人（1995 年出生），釜山本地博主。
* **教育背景**：本科毕业于武汉大学，深耕中文语言与国内大众生活习惯，中文沟通无障碍，懂中国文化。
* **从业经历**：曾在深圳从事物流行业 4 年，长期对接中韩跨境业务，常年往返中韩两地，深度熟知两国文化差异、出行习惯与游客痛点。
* **运营平台**：小红书、抖音、NAVER 博客多平台持续运营，以真实探店、无广内容为主。
* **核心定位与发展初衷**：兼具韩国本土生活底蕴与中国文化认知。因自身是釜山人且最懂中国游客需求，决定深耕釜山本地内容，以“**釜山本地人视角 + 中国游客思维**”带大家玩透、吃透釜山。

## 二、内容理念与服务定位

* **内容特色**：
  * 不同于普通赴韩博主和流水线旅游攻略账号，不照搬网红模板，无商业广告营销与店铺充值种草。
  * 坚持原创实拍、实地探店、亲身实测，拒绝虚假营销和流量套路。
  * 只推荐本地人日常消费、口碑过硬的宝藏老店、本地人私藏打卡地、小众游玩路线与特色游艇出海资源。
* **服务宗旨**：
  * 依托本土成长经历与多年国内生活工作经验，精准拿捏国人旅游喜好，规避水土不服、审美不符、体验感差的出行问题。
  * 致力于为来韩国、来釜山的游客提供真实、靠谱、接地气、适配国人出行习惯的专属旅游攻略、地道美食探店、游艇出海体验与本地生活服务定制推荐，让自由行游客轻松玩转釜山，沉浸式感受本土风土人情。

## 五、解决的痛点问题

测评对象针对中国游客赴釜山旅游普遍面临的痛点，提供针对性解决方案：
1. **语言沟通障碍**：解决因语言不通造成的交流与出行困难。
2. **攻略同质化与过时**：解决攻略千篇一律、信息陈旧、照搬模板的问题。
3. **美食踩雷**：解决找不到地道本地美食、网红店过度营销踩雷的问题。
4. **行程规划困难**：解决游客不会规划行程、行程不合理的问题。
5. **预订流程繁琐**：解决游艇体验、门票等特色项目预订流程繁琐麻烦的问题。
6. **游玩习惯不匹配**：解决市面通用行程不符合国人游玩、饮食及审美习惯的问题。
7. **小众资源缺失**：解决小众特色体验和优质资源无从查找的问题。

   所有攻略、美食探店、景点推荐均为亲身实地打卡、实拍实测，无商业推广、无店铺充值种草，摒弃网红流水线模板内容，只推荐本地人日常消费、口碑过硬的宝藏店铺和小众景点，降低旅游踩雷风险。

   不套用通用模板行程，可根据游客出行天数、亲子 / 情侣 / 闺蜜出行场景、饮食喜好、预算高低，定制专属釜山游玩路线，兼顾热门打卡景点和本地小众特色体验，行程松弛不赶趟、好玩不同质化。
4. **独家本地特色资源**：
   深耕釜山本地多年，掌握小众游艇出海渠道、特色海景游玩机位、本地人私藏美食老店等优质资源，优于 OTA 平台千篇一律的套餐和大众攻略，能带给游客沉浸式深度釜山体验。
5. **一站式省心服务**：
   涵盖行前攻略规划、美食景点避坑、特色项目咨询预订、本地游玩答疑全流程服务，覆盖游客从出行规划到落地游玩的多类需求，让自由行游客无需反复查攻略、对比筛选，轻松省心游玩。
6. **专业靠谱服务底色**：
   4 年深圳跨境工作经验，具备极强的细心、耐心和服务意识，对接沟通高效专业，答疑细致全面，区别于普通博主随意、敷衍的内容输出，服务体验更有保障。
