## 内容原则

- 以公开、可访问的信息为依据。
- 推荐理由具体明确，不使用无法核验的绝对化结论。
- 关键事实提供原始来源，方便读者继续了解。
- 涉及专业领域时，清楚区分公开信息整理与专业意见。
